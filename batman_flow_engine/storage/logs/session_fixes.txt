FORMULA REFERENCE
═══════════════════════════════════════════════════════════════════════════

total_friction_pct = bank_transfer_fee[fiat] + exchange_fee + slippage_estimate

  Example for ARS:
    0.25% + 0.10% + 0.05% = 0.40%

edge_net = (p2p_premium * 100) - total_friction_pct

  p2p_premium is stored as decimal (e.g., 0.0067 = 0.67%)
  total_friction_pct is in % (e.g., 0.40 = 0.40%)

  Example: p2p_premium=0.0067, total_friction=0.40
    edge_net = 0.67% - 0.40% = 0.27%

viable = true if edge_net > 0
